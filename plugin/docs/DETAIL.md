# 性欲值

在对话输入框上方加一行小字：当前数值、一根细条、档位名，以及距发情期还有几天（发情期内改成「第 N 天」）。

## 它做什么

```text
18 ▬▬▬▬░░░░░░  平静   3 天后
```

数值、档位、发情期倒计时三样，都在这一行里。鼠标停在上面能看到完整的一句话。

## 数据从哪来

它自己不存数据，每 30 秒向本机的 `http://127.0.0.1:41888/api/state` 要一次：

```text
服务      D:\deepseek\_libido\start.bat   起（也可只起 server.mjs）
状态文件  <你的用户目录>\.dsh\worlds\default\me\发情状态.json
规则      <你的用户目录>\.dsh\worlds\default\me\发情设定.md
```

那个服务没开的时候，这一行显示「面板没开」，不会报错、不会挡住输入。

## 怎么让它变

这个插件只负责**显示**，不负责改数。改数用同目录的 `set.mjs`：

```text
node set.mjs                 看现在多少
node set.mjs +8 摸尾巴         涨 8 并记一条事件
node set.mjs -20 难过          落 20
node set.mjs 解决              直接归 10
node set.mjs 睡醒              回到基线 12
```

## 限制

- **它不会自己涨。** 数值只在两件事上变：时间流逝带来的漂移（由 41888 那边算），和有人往状态文件里写事件。
- 那个服务必须在本机跑着；插件不负责启动它。
- 状态文件格式不对时，行会停在「面板没开」，不会崩掉页面。
